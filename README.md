# Jungle Cook – Homework 7

This is my Jungle Cook website for Homework 7. It includes a Home page and a Login/Sign Up page.

## Features

- Home and Login pages
- Mobile hamburger menu
- Sign up and log in using Firebase
- Logout button
- Navigation changes after logging in
- Works on phones, tablets, and computers

## How to Run

1. Open the `dist` folder.
2. Upload everything inside it to Web4.
3. Open `index.html` to view the website.
4. Internet is needed for Firebase login and sign up.

## Files

- `index.html` – Home page
- `login.html` – Login and Sign Up page
- `styles.css` – Website design
- `script.js` – Mobile menu
- `firebase-auth.js` – Firebase authentication
- `images/` – Background image

## Firebase

I used Firebase Authentication for signing up, logging in, and logging out.

Firebase project: `jungle-cook-hw7`
